## Зачем этот сайт?

Это мой центральный хаб. Здесь я собираю:

- Ссылки на мои проекты
- Статьи о технологиях
- Заметки и туториалы

## Технологии

Сайт собран на связке:

- **Astro** — для генерации статики
- **Tailwind CSS** — для стилей
- **GitHub Pages** — для хостинга

### Почему Astro?

Astro генерирует чистый HTML без лишнего JavaScript. Это значит:

1. Сайт загружается мгновенно
2. Хорошо индексируется поисковиками
3. Работает везде, даже без JS
