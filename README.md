## 🛠 Технологии

Проект создан с упором на максимальную производительность, чистоту кода и независимость от сложных сборщиков.

*   **HTML5** — Семантическая верстка.
*   **CSS3** — Кастомный дизайн (Flexbox/Grid), адаптивность, Dark Mode.
*   **Vanilla JavaScript (ES6+)** — Логика загрузки проектов (Fetch API).
*   **JSON** — База данных проектов.

Никаких `npm install`, никаких `build` процессов. Чистая статика.
